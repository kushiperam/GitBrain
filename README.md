\# GitBrain – Repository Intelligence Platform



GitBrain is an AI-powered repository intelligence platform that helps developers understand and interact with software repositories using natural-language questions.



Instead of manually searching through files, developers can ask questions about a repository and receive answers grounded in the repository's source code, along with source file and line references.



\## Key Features



\- 🔐 JWT-based authentication

\- 👤 Role-based access control

\- 📦 GitHub repository support

\- 📁 Local repository support

\- 🔎 Repository analysis

\- 🧩 Code chunking

\- 🧠 Semantic code search

\- 📚 Retrieval-Augmented Generation (RAG)

\- 🤖 Local Large Language Model (LLM)

\- 💬 Natural-language repository Q\&A

\- 📌 Source file and line references

\- 🗄️ PostgreSQL database

\- 🧪 Automated backend tests

\- 📖 API documentation

\- 🏗️ Architecture documentation
